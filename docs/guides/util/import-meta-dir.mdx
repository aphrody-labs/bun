title: Get the directory of the current file
description: "Get the absolute path of the directory that contains the current module with `import.meta.dir`."
sidebarTitle: import.meta.dir

---

Bun provides a handful of module-specific utilities on the [`import.meta`](/runtime/module-resolution#importmeta) object. Use `import.meta.dir` to retrieve the absolute path to the directory containing the current file.

```ts /a/b/c.ts icon="/icons/typescript.svg"
import.meta.dir; // => "/a/b"
```

---

See [`import.meta`](/runtime/module-resolution#importmeta).
