---
title: Get the file name of the current file
description: "Get the file name of the current module, such as `c.ts`, with `import.meta.file`."
sidebarTitle: import.meta.file
mode: center
---

Bun provides a handful of module-specific utilities on the [`import.meta`](/runtime/module-resolution#importmeta) object. Use `import.meta.file` to retrieve the name of the current file.

```ts /a/b/c.ts icon="/icons/typescript.svg"
import.meta.file; // => "c.ts"
```

---

See [`import.meta`](/runtime/module-resolution#importmeta).
