## Répartition

`bun:windows` porte les appels système stables et réutilisables. WinClean reste dans Aphrody comme outil produit : il orchestre le computer use, les observations, le nettoyage, l’optimisation et les parcours métier. Il consomme les primitives du fork et conserve ses formats MCP, politiques, filtres et confirmations.

## Paquets Windows séparés

Les dossiers de paquets de familles Win32 générés depuis win32metadata ne sont pas encore présents dans ce checkout Bun. Le lot `sys32` doit établir leur manifest, génération, chargement différé et tests; ce lot ne crée donc pas de faux paquets ou de façades non fonctionnelles. Les familles indiquées dans la table décrivent les destinations attendues et doivent reprendre la forme réelle de `sys32` lors de son intégration.

Le chemin rapide de ce lot ajoute seulement l’énumération des volumes, une capacité système native simple et réutilisable. Elle est appelée à la demande et n’ajoute aucune initialisation au démarrage de Bun. Les API de registre, SCM, processus, journaux, clipboard, tâches Job, notifications et WSL préexistantes restent elles aussi paresseuses via l’import `bun:windows`.

## Repointer Aphrody en T2

Dans le checkout Aphrody (sans modifier les fichiers de ce lot) :

1. Ajouter un adaptateur TypeScript dans `packages/os/winclean/src/` qui importe `bun:windows` et traduit les résultats/erreurs en schéma actuel des tools MCP.
2. Remplacer les chemins `registry.rs`, `services.rs`, `eventlog.rs`, clipboard et lecture de version par `windows.registry`, `windows.services`, `windows.eventLog`, `windows.clipboard` et `windows.version/systemInfo`; basculer `get_disk_info` vers `windows.storage.drives()`.
3. Garder dans `dispatch.rs` le routage, les contrôles, messages utilisateur et fonctions de produit. Garder dans `system.rs`/modules produit les politiques d’optimisation, les seuils et les compositions jusqu’à disponibilité des paquets listés.
4. Éliminer toute dépendance directe Aphrody à `windows`/`windows-sys`/`uiautomation` une fois tous les consommateurs repointés. Revoir les features `target.'cfg(windows)'.dependencies` de `crates/os/kernel/comps/winclean/Cargo.toml`; supprimer seulement celles qui ne sont plus utilisées.
5. Conserver computer use, nettoyage, optimisation, catalogue Steam, base/vault Steam, coordination, WinML/OCR/speech et schémas `tools.json` dans Aphrody. Ces fonctions consomment les API système Bun sans déplacer leur logique produit.
