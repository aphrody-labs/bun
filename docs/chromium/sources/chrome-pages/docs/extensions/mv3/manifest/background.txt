Manifest - background

Stay organized with collections

Save and categorize content based on your preferences.

An optional manifest key used to specify a javascript file as the extension service worker. A service worker is a background script that acts as the extension&#39;s main event handler. For more information, visit the more comprehensive introduction to service workers.
{
...
"background": {
"service_worker": "service-worker.js",
"type": "module"
},
...
}
