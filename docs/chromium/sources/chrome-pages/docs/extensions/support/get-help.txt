Get help with Chrome Extensions

Stay organized with collections

Save and categorize content based on your preferences.

We do our best to improve the content of this site and of the
Chrome Web Store help. Some of you might run into problems
we don&#39;t cover. Fortunately, there are other ways for you to get help.

For extensions development

Join the Chromium Extensions Mailing List to stay up-to-date with the latest changes to the Web Store and the extension platform. It&#39;s also a great place to ask technical questions and many members of the Chrome extensions team monitor and participate in discussions.
StackOverflow has a few tags you should follow and search. The
google-chrome-extension tag covers Chrome Extensions generally.

For Chrome Web Store

Use our One Stop Support
page to get help with issues related to your Chrome Web Store account or items.
