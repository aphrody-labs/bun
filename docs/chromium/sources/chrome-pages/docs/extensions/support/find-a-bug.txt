Find and follow a bug

Stay organized with collections

Save and categorize content based on your preferences.

Before filing a bug or submitting a feature request for extensions, you should
check whether either has already been reported by checking open Chromium issues.
These issues are kept in the Chromium issue tracker. This
database lets you search for and follow any issue that&#39;s been reported for
Chromium.

Open the the issue tracker and use the search box at the top to verify whether the issue has already been reported. Most extension issues are filed under component=Platform&gt;Extensions. For example, a search for component=Platform&gt;Extensions Type=Bug chrome.scripting.executeScript gives you this list of results.
If you find a ticket that matches your bug or feature request, click the star icon to express your interest and to be notified when the bug is updated.
If you&#39;re not signed in, you will be prompted to do so. If you don&#39;t have an account in the issue tracker you may create one by clicking Create account on the sign-in prompt and following the on-screen instructions.

Don&#39;t respond to any bugs or feature requests by saying &quot;me too.&quot; Use the
Chrome Extensions Mailing List
for updates on when a bug will be fixed. However, if you have valuable
information, such as a better test case or a suggested fix, add a comment.
