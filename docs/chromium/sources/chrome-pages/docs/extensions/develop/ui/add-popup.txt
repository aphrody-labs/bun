A popup is an action that displays a window letting users invoke multiple extension features. It&#39;s triggered by a keyboard shortcut, by clicking the extension&#39;s action icon or by calling browser.action.openPopup(). Popups automatically close when the user focuses on some portion of the browser outside of the popup. There is no way to keep the popup open after the user has clicked away.

The following image, taken from the Drink Water Event sample, shows a popup displaying available timer options. Users set an alarm by clicking one of the buttons.

An example of a popup.

Register a popup in the manifest under the &quot;action&quot; key.
{
"name": "Drink Water Event",
...
"action": {
"default_popup": "popup.html"
}
...
}

Implement the popup as you would almost any other web page. Note that any JavaScript used in a popup must be in a separate file.
&lt;html&gt;
&lt;head&gt;
&lt;title&gt;Water Popup&lt;/title&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;img src="./stay_hydrated.png" id="hydrateImage"&gt;
&lt;button id="sampleSecond" value="0.1"&gt;Sample Second&lt;/button&gt;
&lt;button id="min15" value="15"&gt;15 Minutes&lt;/button&gt;
&lt;button id="min30" value="30"&gt;30 Minutes&lt;/button&gt;
&lt;button id="cancelAlarm"&gt;Cancel Alarm&lt;/button&gt;
&lt;script src="popup.js"&gt;&lt;/script&gt;
&lt;/body&gt;
&lt;/html&gt;

You can also create popups dynamically by calling action.setPopup().
browser.storage.local.get('signed_in', (data) =&gt; {
if (data.signed_in) {
browser.action.setPopup({popup: 'popup.html'});
} else {
browser.action.setPopup({popup: 'popup_sign_in.html'});
}
});
