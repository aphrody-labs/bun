Manifest - content scripts

Stay organized with collections

Save and categorize content based on your preferences.

The &quot;content_scripts&quot; key specifies a statically loaded JavaScript or CSS file to be used every time a page is opened that matches a certain URL pattern. Extensions can also inject content scripts programmatically, see Injecting Scripts for details.

Manifest

These are the supported keys for &quot;content_scripts&quot;. Only the &quot;matches&quot; key and either &quot;js&quot; or &quot;css&quot; are required.

manifest.json
{
"name": "My extension",
...
"content_scripts": [
{
"matches": ["https://*.example.com/*"],
"css": ["my-styles.css"],
"js": ["content-script.js"],
"exclude_matches": ["*://*/*foo*"],
"include_globs": ["*example.com/???s/*"],
"exclude_globs": ["*bar*"],     
"all_frames": false,
"match_origin_as_fallback": false,
"match_about_blank": false,
"run_at": "document_idle",
"world": "ISOLATED",
}
],
...
}

Files

Each file must contain a relative path to a resource in the extension&#39;s root directory. Leading slashes (/) are automatically trimmed. The &quot;run_at&quot; key specifies when each file will be injected.

&quot;css&quot; - Array
Optional. An array of CSS file paths, injected in the order of this array, and before any DOM construction or page rendering occurs.
&quot;js&quot; - Array,
Optional. An array of JavaScript file paths, injected in the order they appear in this array, after css files are injected. Each string in the array must be a relative path to a resource in the extension&#39;s root directory. Leading slashes (&#39;/&#39;) are automatically trimmed.

Match URLs

Only the &quot;matches&quot; property is required. Then you can use &quot;exclude_matches&quot;, &quot;include_globs&quot;, and &quot;exclude_globs&quot; to customize which URLs to inject code into. The &quot;matches&quot; key will trigger a warning.

&quot;matches&quot; - Array
Required. Specifies which URL patterns to inject the content scripts into. See Match Patterns for syntax.
&quot;exclude_matches&quot; - Array
Optional. Excludes the URL patterns to inject the content scripts into. See Match Patterns for syntax.
&quot;include_globs&quot; - Array
Optional. Applied after matches to include only those URLs that also match this glob. Intended to emulate the @include Greasemonkey keyword.
&quot;exclude_globs&quot; - Array
Optional. Applied after matches to exclude URLs that match this glob. Intended to emulate the @exclude Greasemonkey keyword.

Glob URLs are those that contain &quot;wildcards&quot; * and question marks. The wildcard * matches any string of any length, including an empty string, while the question mark ? matches any single character.

The content script is injected into a page if:

Its URL matches any &quot;matches&quot; and &quot;include_globs&quot; patterns.
And the URL doesn&#39;t match &quot;exclude_matches&quot; or &quot;exclude_globs&quot; patterns.

Globs and URL matching examples

"include_globs"

manifest.json
{
...
"content_scripts": [
{
"matches": ["https://*.example.com/*"],
"include_globs": ["https://???.example.com/foo/*"],
"js": ["content-script.js"]
}
],
...
}

Matches
https://www.example.com/foo/bar
https://the.example.com/foo/

Does not match
https://my.example.com/foo/bar
https://example.com/foo/*
https://www.example.com/foo

manifest.json
{
...
"content_scripts": [
{
"matches": ["https://*.example.com/*"],
"include_globs": ["*example.com/???s/*"],
"js": ["content-script.js"]
}
],
...
}

Matches
https://www.example.com/arts/index.html
https://www.example.com/jobs/index.html

Does not match
https://www.example.com/sports/index.html
https://www.example.com/music/index.html

"exclude_globs"

manifest.json
{
...
"content_scripts": [
{
"matches": ["https://*.example.com/*"],
"exclude_globs": ["*science*"],
"js": ["content-script.js"]
}
],
...
}

Matches
https://history.example.com
https://.example.com/music

Does not match
https://science.example.com
https://www.example.com/science

Advanced customization example

manifest.json
{
...
"content_scripts": [
{
"matches": ["https://*.example.com/*"],
"exclude_matches": ["*://*/*business*"],
"include_globs": ["*example.com/???s/*"],
"exclude_globs": ["*science*"],
"js": ["content-script.js"]
}
],
...
}

Matches
https://www.example.com/arts/index.html
https://.example.com/jobs/index.html

Does not match
https://science.example.com
https://www.example.com/jobs/business
https://www.example.com/science

Frames

The &quot;all_frames&quot; key specifies if the content script should be injected into all frames matching the specified URL requirements. If set to false it will only inject into the topmost frame. It can be used along with &quot;match_about_blank&quot; to inject into an about:blank frame.

To inject into other frames like data:, blob:, and filesystem:, set the &quot;match_origin_as_fallback&quot; to true. For details, see Inject in related frames

&quot;all_frames&quot; Boolean
Optional. Defaults to false, meaning that only the top frame is matched. If set to true, it will inject into all frames, even if the frame is not the topmost frame in the tab. Each frame is checked independently for URL requirements, it won&#39;t inject into child frames if the URL requirements are not met.
&quot;match_about_blank&quot;- Boolean
Optional. Defaults to false. Whether the script should inject into an about:blank frame where the parent URL matches one of the patterns declared in &quot;matches&quot;.
&quot;match_origin_as_fallback&quot; - Boolean
Optional. Defaults to false. Whether the script should inject in frames that were created by a matching origin, but whose URL or origin may not directly match the pattern. These include frames with different schemes, such as about:, data:, blob:, and filesystem:.

Run time and execution environment

By default, content scripts are injected when the document and all resources are finished loading, and live in a private isolated execution environment that isn&#39;t accessible to the page or other extensions. You can change these defaults in the following keys:

&quot;run_at&quot; - document_start | document_end | document_idle
Optional. Specifies when the script should be injected into the page. It corresponds with the loading states of Document.readyState:

&quot;document_start&quot;: the DOM is still loading.
&quot;document_end&quot;: the page&#39;s resources are still loading
&quot;document_idle&quot;: the DOM and resources have finished loading. This is the default.

&quot;world&quot; - ISOLATED | MAIN
Optional. The JavaScript world for a script to execute within. Defaults to &quot;ISOLATED&quot;, which is the execution environment unique to the content script. Choosing the &quot;MAIN&quot; world means the script will share the execution environment with the host page&#39;s JavaScript. See Work in isolated worlds to learn more.

Warning: There are risks involved when using the &quot;MAIN&quot; world. The host page can access and interfere with the injected script. See Work in isolated worlds to learn more.
