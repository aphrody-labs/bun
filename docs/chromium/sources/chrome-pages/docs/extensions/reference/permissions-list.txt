Permissions

Permissions

Stay organized with collections

Save and categorize content based on your preferences.

To access most extension APIs and features, you must declare permissions in your
extension&#39;s manifest. Some permissions
trigger warnings that users must allow to continue using the extension.

For more information on how permissions work, see Declare permissions. For best
practices for using permissions with warnings, see Permission warning guidelines.

The following is a list of all available permissions and any warnings triggered
by specific permissions.

&quot;accessibilityFeatures.modify&quot;
Lets extensions modify accessibility feature states when using the
chrome.accessibilityFeatures API.

Warning displayed: Change your accessibility settings.

&quot;accessibilityFeatures.read&quot;
Lets extensions read accessibility states when using the
chrome.accessibilityFeatures API.

Warning displayed: Read your accessibility settings.

&quot;activeTab&quot;
Gives temporary access to the active tab through a user gesture. For details,
see activeTab.

&quot;alarms&quot;
Gives access to the
chrome.alarms API.

&quot;audio&quot;
Gives access to the
chrome.audio API.

&quot;background&quot;
Makes Chrome start up early (as soon as the user logs into their computer,
before they launch Chrome), and shut down late (even after its last window is
closed, until the user explicitly quits Chrome).

&quot;bookmarks&quot;
Gives access to the
chrome.bookmarks API.

Warning displayed: Read and change your bookmarks.

&quot;browsingData&quot;
Gives access to the
chrome.browsingData API.

&quot;certificateProvider&quot;
Gives access to the chrome.certificateProvider
API.

&quot;clipboardRead&quot;
Lets the extension paste items from the clipboard using the web platform Clipboard API.

Warning displayed: Read data you copy and paste.

&quot;clipboardWrite&quot;
Lets the extension cut and copy items to the clipboard using the web platform Clipboard API.

Warning displayed: Modify data you copy and paste.

&quot;contentSettings&quot;
Gives access to the
chrome.contentSettings
API.

Warning displayed: Change your settings that control websites&#39; access to
features such as cookies, JavaScript, plugins, geolocation, microphone, camera
etc.

&quot;contextMenus&quot;
Gives access to the
chrome.contextMenus API.

&quot;cookies&quot;
Gives access to the
chrome.cookies API.

&quot;debugger&quot;
Gives access to the
chrome.debugger API.

Warnings displayed:

Access the page debugger backend.
Read and change all your data on all websites.

&quot;declarativeContent&quot;
Gives access to the
chrome.declarativeContent
API.

&quot;declarativeNetRequest&quot;
Gives access to the
chrome.declarativeNetRequest
API.

Warning displayed: Block content on any page.

&quot;declarativeNetRequestWithHostAccess&quot;
Gives access to the chrome.declarativeNetRequest
API but requires host permissions for all actions.

&quot;declarativeNetRequestFeedback&quot;
Gives permission to write errors and warnings to the DevTools console when
using the chrome.declarativeNetRequest
API. This permission is for use with unpacked extensions and is ignored for
extensions installed from the Chrome Web Store.

Warning displayed: Read your browsing history.

&quot;dns&quot;
Gives access to the chrome.dns API. 

&quot;desktopCapture&quot;
Gives access to the
chrome.desktopCapture
API.

Warning displayed: Capture content of your screen.

&quot;documentScan&quot;
Gives access to the
chrome.documentScan API.

&quot;downloads&quot;
Gives access to the
chrome.downloads API.

Warning displayed: Manage your downloads.

&quot;downloads.open&quot;
Allows the use of chrome.downloads.open().

Warning displayed: Manage your downloads.

&quot;downloads.ui&quot;
Allows the use of chrome.downloads.setUiOptions().

Warning displayed: Manage your downloads.

&quot;enterprise.deviceAttributes&quot;
Gives access to the chrome.enterprise.deviceAttributes
API.

&quot;enterprise.hardwarePlatform&quot;
Gives access to the chrome.enterprise.hardwarePlatform
API.

&quot;enterprise.networkingAttributes&quot;
Gives access to the chrome.enterprise.networkingAttributes
API.

&quot;enterprise.platformKeys&quot;
Gives access to the chrome.enterprise.platformKeys
API.

&quot;favicon&quot;
Grants access to the Favicon API.

Warning displayed: Read the icons of the
websites you visit.

&quot;fileBrowserHandler&quot;
Gives access to the chrome.fileBrowserHandler
API.

&quot;fileSystemProvider&quot;
Gives access to the chrome.fileSystemProvider
API.

&quot;fontSettings&quot;
Gives access to the
chrome.fontSettings API.

&quot;gcm&quot;
Gives access to the chrome.gcm and
chrome.instanceID APIs.

&quot;geolocation&quot;
Allows the extension to use the geolocation API without prompting the user for
permission.

Warning displayed: Detect your physical location.

&quot;history&quot;
Gives access to the
chrome.history API.

Warning displayed: Read and change your browsing history on all signed-in
devices.

&quot;identity&quot;
Gives access to the
chrome.identity API.

&quot;identity.email&quot;
Gives access to the user&#39;s email address through the
chrome.identity API.

Warning displayed: Know your email address.

&quot;idle&quot;
Gives access to the chrome.idle API.

&quot;loginState&quot;
Gives access to the
chrome.loginState API.

&quot;management&quot;
Gives access to the
chrome.management API.

Warning displayed: Manage your apps, extensions, and themes.

&quot;nativeMessaging&quot;
Gives access to the native messaging API.

Warning displayed: Communicate with cooperating native applications.

&quot;notifications&quot;
Gives access to the
chrome.notifications API.

Warning displayed: Display notifications.

&quot;offscreen&quot;
Gives access to the
chrome.offscreen API.

&quot;pageCapture&quot;
Gives access to the
chrome.pageCapture API.

Warning displayed: Read and change all your data on all websites.

&quot;platformKeys&quot;
Gives access to the
chrome.platformKeys API.

&quot;power&quot;
Gives access to the
chrome.power API.

&quot;printerProvider&quot;
Gives access to the
chrome.printerProvider
API.

&quot;printing&quot;
Gives access to the
chrome.printing API.

&quot;printingMetrics&quot;
Gives access to the
chrome.printingMetrics
API.

&quot;privacy&quot;
Gives access to the
chrome.privacy API.

Warning displayed: Change your privacy-related settings.

&quot;processes&quot;
Gives access to the chrome.processes API.

&quot;proxy&quot;
Gives access to the chrome.proxy
API.

Warning displayed: Read and change all your data on all websites.

&quot;publicSuffix&quot;
Gives access to the
chrome.publicSuffix API.

&quot;readingList&quot;
Gives access to the
chrome.readingList API.

Warning displayed: Read and change entries in the reading list.

&quot;runtime&quot;
Gives access to runtime.connectNative()
and runtime.sendNativeMessage().
For all other features of the runtime namespace, no permission is required.

&quot;scripting&quot;
Gives access to the
chrome.scripting API.

&quot;search&quot;
Gives access to the
chrome.search API.

&quot;sessions&quot;
Gives access to the
chrome.sessions API.

Warnings displayed:

When used with the &quot;history&quot; permission: Read and change your browsing
history on all your
signed-in devices. 
When used with the &quot;tabs&quot; permission: Read your browsing history on all
your signed-in devices.

&quot;sidePanel&quot;
Gives access to the
chrome.sidePanel API.

&quot;storage&quot;
Gives access to the
chrome.storage API.

&quot;system.cpu&quot;
Gives access to the
chrome.system.cpu API.

&quot;system.display&quot;
Gives access to the
chrome.system.display
API.

&quot;system.memory&quot;
Gives access to the
chrome.system.memory
API.

&quot;system.storage&quot;
Gives access to the
chrome.system.storage
API.

Warning displayed: Identify and eject storage devices.

&quot;tabCapture&quot;
Gives access to the
chrome.tabCapture API.

Warning displayed: Read and change all your data on all websites.

&quot;tabGroups&quot;
Gives access to the
chrome.tabGroups API.

Warning displayed: View and manage your tab groups.

&quot;tabs&quot;
Gives access to privileged fields of the Tab objects used by several APIs,
including chrome.tabs and
chrome.windows. You usually
don&#39;t need to declare this permission to use those APIs.

Warning displayed: Read your browsing history.

&quot;topSites&quot;
Gives access to the
chrome.topSites API.

Warning displayed: Read a list of your most frequently visited websites.

&quot;tts&quot;
Gives access to the chrome.tts API.

&quot;ttsEngine&quot;
Gives access to the
chrome.ttsEngine API.

Warning displayed: Read all text spoken using synthesized speech.

&quot;unlimitedStorage&quot;
Provides an unlimited quota for chrome.storage.local,
IndexedDB,
Cache Storage,
and Origin Private File System.
For more information, see Storage and cookies.

&quot;userScripts&quot;
Gives access to the
chrome.userScripts API. NOTE:
the user must also
explicitly enable
the usage of user scripts.

&quot;vpnProvider&quot;
Gives access to the
chrome.vpnProvider API.

&quot;wallpaper&quot;
Gives access to the
chrome.wallpaper API.

&quot;webAuthenticationProxy&quot;
Gives access to the chrome.webAuthenticationProxy
API.

Warning displayed: Read and change all your data on all websites.

&quot;webNavigation&quot;
Gives access to the
chrome.webNavigation
API.

Warning displayed: Read your browsing history.

&quot;webRequest&quot;
Gives access to the
chrome.webRequest API.

&quot;webRequestBlocking&quot;
Allows the use of the
chrome.webRequest API for
blocking.
