Workbox

Framework integrations

Stay organized with collections

Save and categorize content based on your preferences.

Frameworks make web development more enjoyable through an improved developer experience. While Workbox can be used in any project regardless of what framework it uses&mdash;or whether it uses a framework at all&mdash;some frameworks have integrations with Workbox that make it even easier to use. Below are setups that include Workbox out of the, well, box.

React/React-compatible

create-react-app
gatsby-plugin-offline
preact-cli
next/pwa
next-offline

Vue

@vuepress/plugin-pwa
@vue/cli-plugin-pwa
