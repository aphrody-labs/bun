Chrome ad experience measurements

Chrome provides public metrics and tooling for sites and others, like advertisers, to better understand real users' ad experiences and their impact.

Metrics overview

CrUX ad metrics

Chrome publishes experimental metrics about Chrome users' ad experiences from Chrome users through the Chrome User Experience Report (CrUX). Use CrUX Vis for a quick view of these metrics for eligible sites at an origin and page-level.

AdCount

The Ad Count metric describes how many ads a typical user is seeing at once on the site.

Learn more about ad count

AdDensity

The Ad Density metric describes a typical user's balance of content and advertising visibility.

Learn more about ad density

Ad Weight:CPU

The Ad Weight: CPU metric describes the CPU consumption by ads, which can impact performance.

Learn more about ad weight CPU

Ad Weight:Network

The Ad Weight: Network metric describes the network resources consumption by ads, which can impact performance.

Learn more about ad weight network
