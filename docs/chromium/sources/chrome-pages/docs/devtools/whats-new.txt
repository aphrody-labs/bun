The What&#39;s new panel in DevTools features highlights from our What&#39;s new in DevTools blog series.

Overview

With each update to Chrome DevTools, we release a new article in our blog series What&#39;s new in DevTools.
The What&#39;s new panel features some of the more interesting changes from the update. Each change has a short description for your quick reference.
Note: The What&#39;s new panel in Chrome DevTools focuses on DevTools features only. The &#39;What&#39;s new&#39; tab in Chrome showcases general Chrome updates instead.

Click any of the titles to open the relevant section in the newest blog in a new tab.
The See all new features button at the top takes you to the latest article from this series.

The video banner will take you to a video with important highlights from previous versions.

Open the What's new panel in DevTools

By default, the What&#39;s new panel in DevTools opens automatically after each Chrome update.

To prevent the What&#39;s new panel from opening automatically in DevTools, clear the following checkbox in DevTools settings: Preferences &gt; Appearance &gt; check_box_outline_blank Show what&#39;s new after each update.

To manually open the What&#39;s new panel:

Open DevTools.
Open the Command menu by pressing:

macOS: Command+Shift+P
Windows, Linux, ChromeOS: Control+Shift+P

Start typing what&#39;s new, select Show what&#39;s new, and press Enter. DevTools displays the What&#39;s new panel in the Drawer at the bottom of your DevTools window.

Alternatively, you can open the What&#39;s new panel in the following ways:

In the action bar at the top, click double_arrow More panels and select What&#39;s new from the drop-down list.
In the top right corner, select more_vert Customize and control DevTools &gt; More tools &gt; What&#39;s new.
