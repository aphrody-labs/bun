Deleting Chrome Web Store developer accounts

Stay organized with collections

Save and categorize content based on your preferences.

This page describes how to delete CWS developer accounts and publishers.

About account deletion

Items in the Chrome Web Store are associated with developer and publisher
accounts. There are a few things you need to understand before you delete an
account:

Account deletion is permanent. There is no &quot;undo&quot; for this action.
You can&#39;t delete a publisher that still has published items. If you have
published items, make sure to unpublish them before you
try and delete the publisher.
Publishers can only be deleted by an Admin of the publisher.
You can&#39;t delete a developer that is the last Admin of a publisher. You will
need to share ownership or delete the publisher
before you can delete the developer.

How to remove a store listing item

Visit the developer dashboard. Click the item you want to
remove from the store, so that the edit page for that item appears. Then click
the &quot;more options&quot; icon in the top right-hand corner and select Unpublish.
Your listing will no longer be visible in the store.

Warning: Re-publishing an extension that has been previously unpublished requires you to submit a new version, which needs to go through the review process again.
How to delete a developer account

Navigate to the Delete account section on the Account &gt; Profile page
on the Chrome Web Store Developer Dashboard and click the Delete developer account
button to permanently delete the developer account.

If this developer is the last Admin for any publishers, an error dialog will
list the publishers that must be shared or deleted before the developer can
be deleted.

How to delete a publisher account

To delete a publisher account, select it using the
&quot;Publisher&quot; pulldown at the top of the Developer Dashboard. Make sure that you
have unpublished any items associated with the publisher.

Navigate to the Delete publisher section on the Publisher &gt; Settings page:

Click Delete publisher, verify the publisher details and check the confirmation
box in the dialog, and click Delete publisher to permanently delete the publisher
account.
