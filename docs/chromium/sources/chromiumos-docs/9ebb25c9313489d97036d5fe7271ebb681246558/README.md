# ChromiumOS docs

As of Q1 2024, The ChromiumOS docs repository is deprecated. Please visit the
[ChromiumOS Developer Library](https://chromium.org/chromium-os/developer-library)
to access the documentation previously hosted here. If you are planning to
contribute documentation, please read the library's
[Contributor's guide](https://chromium.org/chromium-os/developer-library/contributing).

For more information about the Developer Library, please read the library
[proposal](https://www.chromium.org/chromium-os/developer-library/proposal/).
