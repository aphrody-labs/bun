Native tools of `bun mcp` for coding agents: digest a directory and read the installed sources and docs of a project's dependencies, offline and at their exact versions.

## `git_ingest`: Directory digest

Turn a local directory or a subpath of it into a prompt-ready digest in the GitIngest layout: a summary, the directory tree and the content of every text file. Honors .gitignore, skips binary files and files over max_file_size.

| Argument | Type | Description |
| --- | --- | --- |
| `source` | string | Directory to ingest, absolute or relative to the working directory. Defaults to the working directory. |
| `subpath` | string | Subdirectory of source to restrict the digest to. |
| `include_patterns` | string[] | Glob patterns a file must match, e.g. "*.rs" or "src/**/*.ts". |
| `exclude_patterns` | string[] | Glob patterns to skip, on top of .gitignore. |
| `max_file_size` | integer, min 1 | Largest file to include, in bytes. Default 10485760. |
| `max_total_bytes` | integer, min 1 | Stop adding file contents past this many bytes. Default 16777216. |

## `deps_list`: List dependencies

List the dependencies of a project whose sources are on disk: npm packages from package.json resolved through node_modules, Cargo packages from Cargo.lock resolved in the Cargo registry and git checkouts, and directories under vendor/. Each entry has its ecosystem, version and local path.

| Argument | Type | Description |
| --- | --- | --- |
| `root` | string | Project root. Defaults to the working directory. |
| `ecosystem` | "npm" \| "cargo" \| "vendor" | Only list this ecosystem. |
| `filter` | string | Case-insensitive substring the name must contain. |
| `limit` | integer, min 1 | Maximum entries. Default 500. |

## `deps_info`: Dependency facts

Facts about one dependency read from its installed manifest: version, local path, license, repository, homepage, description and the documentation files it ships.

| Argument | Type | Description |
| --- | --- | --- |
| `name` | string (required) | Package, crate or vendor directory name. |
| `root` | string | Project root. Defaults to the working directory. |
| `ecosystem` | "npm" \| "cargo" \| "vendor" | Disambiguate when the name exists in several ecosystems. |

## `deps_tree`: Dependency tree

List a directory of a dependency's installed sources.

| Argument | Type | Description |
| --- | --- | --- |
| `name` | string (required) | Package, crate or vendor directory name. |
| `path` | string | Directory inside the dependency. Defaults to its root. |
| `depth` | integer, min 1, max 8 | Levels to descend. Default 2. |
| `root` | string | Project root. Defaults to the working directory. |
| `ecosystem` | "npm" \| "cargo" \| "vendor" |  |

## `deps_read`: Read a dependency file

Read one file of a dependency's installed sources. Text past max_bytes is cut and the result is flagged truncated.

| Argument | Type | Description |
| --- | --- | --- |
| `name` | string (required) | Package, crate or vendor directory name. |
| `path` | string (required) | File inside the dependency, e.g. "README.md" or "src/lib.rs". |
| `offset` | integer, min 0 | Byte offset to start at. Default 0. |
| `max_bytes` | integer, min 1 | Bytes to return. Default 262144. |
| `root` | string | Project root. Defaults to the working directory. |
| `ecosystem` | "npm" \| "cargo" \| "vendor" |  |

## `deps_search`: Search dependency sources

Regular-expression search over the installed sources of one or more dependencies, in parallel. Returns file, line and the matching line.

| Argument | Type | Description |
| --- | --- | --- |
| `query` | string (required) | Regular expression (Rust regex syntax). |
| `names` | string[] (required) | Dependencies to search. |
| `glob` | string[] | Only search files matching these globs. |
| `case_insensitive` | boolean | Default false. |
| `max_results` | integer, min 1 | Default 100. |
| `root` | string | Project root. Defaults to the working directory. |

## `deps_docs`: Search dependency documentation

Rank the documentation shipped by installed dependencies (README, *.md, *.mdx, docs/, *.d.ts) against a query and return the best sections. Offline counterpart of a web documentation search, pinned to the installed versions.

| Argument | Type | Description |
| --- | --- | --- |
| `query` | string (required) | Words to look for. |
| `names` | string[] | Restrict to these dependencies. Defaults to every npm and vendor dependency. |
| `max_results` | integer, min 1, max 50 | Default 8. |
| `root` | string | Project root. Defaults to the working directory. |
