To upgrade:

```bash
bun upgrade
```

To install:

```bash
curl https://bun.sh/install | bash
```

{% details summary="If you have any problems upgrading" %}

Run the install script (you can run it multiple times):

```bash
curl https://bun.sh/install | bash
```

{% /details %}
