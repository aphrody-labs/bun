# bun-pkg

Package contracts and metadata parsers (npm, Cargo sparse, NuGet, vcpkg, PyPI), verified blob store, bounded HTTP ingestion and the store command line.

Restored in `packages/os` of the Bun fork from the published legacy crate `bun_pkg` 1.4.7 (library `bun_pkg`). Not published: `publish = false`.
