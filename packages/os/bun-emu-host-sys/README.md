# bun-emu-host-sys

Raw bindings (bindgen, runtime-loaded) to the Bun OS emulator host C ABI (include/bun_emu_host.h).

Restored in `packages/os` of the Bun fork from the published legacy crate `bun-emu-host-sys` 0.1.0 (library `bun_emu_host_sys`). Not published: `publish = false`.
