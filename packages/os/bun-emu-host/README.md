# bun-emu-host

Safe Rust API over the Bun OS emulator host: melonDS, Dolphin, Azahar and Kyty cores as headless libraries.

Restored in `packages/os` of the Bun fork from the published legacy crate `bun-emu-host` 0.1.0 (library `bun_emu_host`). Not published: `publish = false`.
