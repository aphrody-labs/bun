# bun-dotnet-host

CLR host for Bun: locates hostfxr (nethost semantics), runs the dotnet muxer in-process and binds UnmanagedCallersOnly entry points.

Restored in `packages/os` of the Bun fork from the published legacy crate `bun-dotnet-host` 1.4.8 (library `bun_dotnet_host`). Not published: `publish = false`.
