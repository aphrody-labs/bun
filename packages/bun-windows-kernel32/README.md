# @aphrody/bun-windows-kernel32

Déclarations Win32 pour bun:ffi, générées depuis Microsoft.Windows.SDK.Win32Metadata 71.0.30-preview. L'ouverture de DLL est explicite et à la demande via open().

DLL couvertes : kernel32.dll, kernelbase.dll.

1414 fonctions exportées. Les noms W sont préférés par wideAliases; les variantes A restent accessibles. Les signatures exposent l'indication SetLastError fournie par les métadonnées.

Les tailles et offsets de structures sont fournis dans structs. Les énumérations sont exposées dans enums.
