name: bun-video
description: Author React Remotion or HTML HyperFrames video, inspect runtime capabilities and stream qualified native frames.
---

Use the unified `bun-video` executable: `remotion <command>` or
`hyperframes <command>`. Preserve each project's license and pinned provenance.
Read `../../../README.md` and the relevant upstream documentation before choosing
the renderer. Use `capabilities` first: missing browser/tooling symbols are a
blocked provider, not a successful render. The library exposes actual upstream
functions and bounded worker capture. Use `encodeVideo` with the qualified native
media binary and absolute output path. FFV1 is the exact 8-bit RGBA path; GPU H264
requires explicit lossy opt-in and successful device probing.

For an agent, use `registerVideoTools` inside the canonical capability owner, or
the executable's stdio `mcp` command. `video_browser_task` creates a fresh origin
restricted context; it never imports cookies or provider sessions. DOM actions
run through the native context's evaluation API. An open-weight local model can
call the same tools; model quality and autonomous task completion require their
own qualification. Do not install a deprecated MCP alias.

Remotion source documentation: `remotion/packages/docs/docs/`. HyperFrames source
documentation and authoring references remain under `hyperframes/`. Benchmark
actual equal inputs and compare frame hashes before reporting acceleration.
